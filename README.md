# Alberto & Bernardete — Império do Amor ❤️🎲

Jogo original de tabuleiro online, inspirado em jogos de compra e gestão de propriedades. Node.js, Express e Socket.IO.

## Incluído nesta primeira versão
- Salas privadas, 2–4 jogadores, sincronização em tempo real
- Tabuleiro de 40 casas, dados e turnos
- Compra de propriedades e leilões com lances
- Rendas, impostos e cartas de sorte
- Construção equilibrada de casas e hotéis
- Hipotecas e desipotecas
- Prisão, saída pagando ou com duplas, falência

## Testar no computador
1. Instala Node.js 18+: https://nodejs.org/
2. Extrai o ZIP.
3. Abre o terminal na pasta do projeto e executa `npm install`
4. Executa `npm start`
5. Abre http://localhost:3000

## Publicar
1. Cria um repositório GitHub chamado `imperio-do-amor`.
2. Envia os ficheiros da raiz deste ZIP e a pasta `public/` para o repositório.
3. No Render: New + → Web Service → liga o repositório.
4. Build Command: `npm install`; Start Command: `npm start`.
5. Escolhe Free, se disponível, e clica Create Web Service.
6. Quando aparecer Live, abre o endereço onrender.com.

## Importante
Esta é a primeira versão jogável e precisa de testes reais. O estado das partidas fica na memória e perde-se se o serviço reiniciar. O plano gratuito do Render pode suspender o serviço por inatividade. Nome, tabuleiro, arte e textos são originais; não é uma cópia do Monopoly.
